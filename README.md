- Добавлено меню для телефонов и планшетов: услуги, цены, процесс работы, отзывы, контакты и MAX. Работает на стандартном элементе details; Escape закрывает меню при работающем скрипте.

- Высота анимационного блока уменьшена с 640vh до 400vh; по пожеланию владельца все дополнительные кнопки первого экрана («Цены на работы», «Как добраться», «Меньше анимации») удалены. Разделы доступны из навигации, уменьшение движения учитывает системную настройку устройства.
- Ссылки в невидимых кадрах исключаются из фокуса клавиатуры. Переходы по разделам учитывают закреплённую шапку.
- Декоративная схема заменена настоящей картой Яндекса с меткой адреса. Рядом находятся адрес, часы работы, актуальный телефон и независимая ссылка «Построить маршрут». До 800px карта размещается под адресом. Виджет загружается отложенно, без отдельной библиотеки сайта.
- Плавающая кнопка MAX постоянно видна при прокрутке, включая контакты и подвал, на компьютере и телефоне. По пожеланию владельца автоматическое скрытие удалено. MAX также доступен из меню и контактов.
- Добавлены часы работы на статичном первом экране и подтверждённая владельцем формулировка о предоставлении условий гарантии на месте.
- Исправлены минимальная цена в структурированных данных (500 ₽), ссылка на звонок под прайсом, цвета печатных документов и срок ответа на запрос о персональных данных.
- Добавлены Content Security Policy в HTML и явная Referrer Policy; обновлены даты документов и sitemap.

## Как применить

Сохраните предыдущую версию перед обновлением. Перенесите в ветку/каталог, из которых реально публикуется GitHub Pages, файлы `index.html`, `privacy.html`, `consent.html`, `sitemap.xml`, `assets/site.js`, `assets/doc.css`. Эта папка также содержит прежние изображения и шрифты, поэтому подходит для полной публикации статического сайта. Не меняйте настройки ветки публикации наугад: проверьте текущий источник в Settings → Pages.

В пакете нет учётных данных, серверной части или дополнительных библиотек. Достаточно обычного статического хостинга. При простом открытии index.html локально доступность ресурсов определяется правилами браузера; для проверки используйте локальный веб-сервер.

Сайт публикуется GitHub Pages из ветки `claude/autobatya-shop-website-cog490`, каталог `/ (root)`. После обновления проверьте страницу в новой вкладке, на телефоне, переходы к ценам и контактам, открытие MAX и Яндекс Карт. Реальные звонки и переписку следует проверять владельцу.

1. В Яндекс Бизнесе заменить старый номер на **+7 904 017-25-88** и старую ссылку avtobatya.tb.ru на текущий сайт.

3. Проверить юридические документы применительно к реальной работе ИП. Исправление одного срока не является полной юридической экспертизой.
4. robots.txt должен обслуживаться в корне домена (`https://fallen555.github.io/robots.txt`). Файл внутри `/AutoBatya-NEW/` этого не заменяет. Альтернатива для обнаружения sitemap — отправить его в кабинеты вебмастеров.
5. Для защиты от встраивания сайта в чужие страницы понадобятся HTTP-заголовки хостинга: `Content-Security-Policy: frame-ancestors 'none'` и, при необходимости совместимости, `X-Frame-Options: DENY`. Настройте также `X-Content-Type-Options: nosniff`. Не пытайтесь заменить их meta-тегами или файлом _headers, который текущий хостинг не обрабатывает.

## Особенности новой защиты

CSP разрешает локальные скрипты, изображения и шрифты, запрещает внешние скрипты основной страницы и её сетевые API-запросы. Для карты разрешены iframe только с https://yandex.ru и https://yandex.com; содержимое виджета работает по правилам Яндекса. В политике описана загрузка внешней карты. Inline-стили разрешены, потому что оформление использует их. Это дополнительное ограничение, а не доказательство отсутствия уязвимостей. Защиту от iframe meta-CSP не обеспечивает.

Если в будущем подключите Метрику, форму или внешние виджеты, сначала отдельно проверьте необходимость согласия, политику обработки данных и минимально необходимые изменения CSP. Простое добавление счётчика сейчас будет заблокировано политикой.

При переходе на собственный домен обновите все абсолютные адреса: canonical, Open Graph, Twitter, JSON-LD, sitemap и robots.txt. Одних двух meta-тегов недостаточно.
