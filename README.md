# АвтоБатя

Сайт автомастерской «АвтоБатя», Тверь, улица Вагжанова 11к2.

Одна страница, обычные HTML, CSS и JavaScript. Ни сборки, ни библиотек, ни сторонних запросов.

## Что где лежит

```
index.html            вся страница и стили
assets/site.js        прокрутка героя, появления, свет в боксе
assets/hero-scrub.mp4 ролик, который проматывается прокруткой
assets/fonts/         шрифты, лежат рядом с сайтом
brief/                дизайн-пакет: палитра, тексты, карта остановок
```

## Как открыть у себя

Просто открыть `index.html` двойным щелчком можно, но браузер в таком режиме запрещает загрузку видео,
и вы увидите статичную заставку. Это нормально и так задумано.

Чтобы посмотреть прокрутку с видео, поднимите любой локальный сервер в папке сайта:

```
python3 -m http.server 8080
```

и откройте `http://127.0.0.1:8080` в браузере.

## Как выложить в интернет

GitHub Pages, бесплатно:

1. Settings, слева пункт Pages.
2. Source: Deploy from a branch.
3. Branch: `claude/autobatya-shop-website-cog490`, папка `/ (root)`, Save.
4. Через пару минут адрес появится там же, сверху страницы.

После этого в `index.html` нужно подставить рабочий адрес в двух местах, они помечены комментарием
`<!-- DEPLOY STEP -->`. Это нужно только для красивой карточки, когда ссылкой делятся в мессенджере.

## Что можно дописать позже

- Настоящий прайс и настоящие отзывы, для них готовы места на странице.
- Кнопка «Написать в MAX», как только будет личная ссылка вида `max.ru/u/...`.
  Место для неё отмечено комментарием в блоке контактов.

## Про шрифты

В файлах шрифтов только нужные символы: русский алфавит, латиница, цифры и знаки препинания.
Если в текст попадёт редкий символ, например греческая буква, он покажется системным шрифтом.
