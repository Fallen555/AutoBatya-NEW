# Чат на сайте: как включить

Чат уже написан и лежит в проекте. Осталось завести для него бесплатное хранилище,
чтобы сообщения где-то жили и доходили до вас. Всё бесплатно, платить ни за что не нужно.
Займёт минут двадцать, делается один раз.

Пока адрес функции не вписан, кнопка чата на сайте просто не показывается,
и сайт работает как обычно.

## Что получится

- В правом нижнем углу сайта кнопка. Клиент открывает окно, пишет, может приложить
  фото или видео и поставить смайлик.
- Вам на почту падает письмо о новом сообщении.
- Вы открываете страницу `pult.html` на сайте, вводите пароль и отвечаете. Ответ
  появляется у клиента прямо в окне чата, обычно в течение шести секунд.
- Переписка не теряется: клиент вернётся на сайт через неделю и увидит её.

## Шаг 1. Проект в Supabase

1. Откройте supabase.com и нажмите **Start your project**. Войти можно через GitHub.
2. **New project**. Имя: `avtobatya`. Регион возьмите ближайший, например Frankfurt.
3. Придумайте пароль базы и сохраните его у себя. В чате он больше не понадобится.
4. Нажмите **Create new project** и подождите пару минут, пока проект поднимется.

## Шаг 2. Таблицы и хранилище файлов

1. Слева **SQL Editor**, кнопка **New query**.
2. Откройте файл `chat-backend/schema.sql` из этого репозитория, скопируйте всё
   содержимое, вставьте в окно и нажмите **Run**.
3. Внизу должно появиться `Success`. В разделе **Storage** появится ведро `chat-files`,
   оно закрытое, снаружи файлы не открыть, ссылки на них выдаёт только наша функция
   и живут они час.

## Шаг 3. Ключ для писем (можно пропустить и сделать позже)

1. Откройте web3forms.com, введите почту, куда хотите получать уведомления.
2. На эту почту придёт **Access Key**, длинная строка. Скопируйте её.

Без ключа чат работает, просто письма приходить не будут, и новые сообщения
вы увидите, только когда откроете пульт.

## Шаг 4. Функция

1. Слева **Edge Functions**, кнопка **Deploy a new function**, затем **Via Editor**.
2. Имя функции: `chat`. Ровно так, маленькими буквами.
3. Удалите пример из окна и вставьте всё содержимое файла
   `chat-backend/functions/chat/index.ts`.
4. Нажмите **Deploy function**.
5. Откройте настройки функции и **выключите Verify JWT**. Пункт называется
   `Verify JWT with legacy secret`. Это обязательно, иначе сайт не сможет
   достучаться до функции.

## Шаг 5. Пароль и остальные настройки

Слева **Edge Functions**, вкладка **Secrets** (в некоторых версиях панели это
**Project Settings → Edge Functions → Secrets**). Добавьте четыре строки:

| Имя | Значение |
|---|---|
| `SHOP_PASSWORD` | пароль, которым вы будете входить в пульт. Придумайте посложнее |
| `NOTIFY_KEY` | ключ из шага 3, если делали. Иначе строку не добавляйте |
| `SITE_URL` | `https://fallen555.github.io/AutoBatya-NEW` |
| `ALLOWED_ORIGIN` | `https://fallen555.github.io` |

`SUPABASE_URL` и `SUPABASE_SERVICE_ROLE_KEY` добавлять не нужно, Supabase
подставляет их сам.

## Шаг 6. Вписать адрес функции в сайт

1. В Supabase на странице функции скопируйте её адрес. Он выглядит так:
   `https://abcdefghijk.supabase.co/functions/v1/chat`
2. Откройте в репозитории файл `assets/chat-config.js` и вставьте адрес в кавычки:

```js
window.AUTOBATYA_CHAT = {
  endpoint: "https://abcdefghijk.supabase.co/functions/v1/chat"
};
```

3. Сохраните и дождитесь, пока GitHub Pages обновит сайт, это минута или две.

Не хотите править файл сами, просто пришлите адрес функции в чат, я впишу.

## Шаг 7. Проверка

1. Откройте сайт. В правом нижнем углу появилась кнопка чата.
2. Напишите тестовое сообщение, приложите фото.
3. На почту должно прийти письмо.
4. Откройте `https://fallen555.github.io/AutoBatya-NEW/pult.html`, введите пароль
   из `SHOP_PASSWORD`. Увидите диалог, ответьте.
5. Вернитесь на сайт: ответ появится в окне чата.

Пульт удобно повесить закладкой на телефоне: работает и с него.

## Что стоит знать

- **Ограничения бесплатного тарифа Supabase.** Полгигабайта базы и гигабайт файлов.
  Для переписки автосервиса это годы работы. Если проект не трогать два месяца,
  Supabase его засыпает, письмо с предупреждением приходит заранее, будится одной
  кнопкой.
- **Пароль пульта.** Меняется в Secrets в любой момент, сайт трогать не надо.
- **Файлы.** До 10 МБ, до четырёх штук за раз. Принимаем фото, PDF и видео mp4.
- **Где лежат данные.** Серверы Supabase находятся за границей. Для обычной
  переписки это рабочая практика, но если нужен строгий 152-ФЗ с хранением
  в России, скажите, переделаю на российский хостинг.
- **Спам.** Чат не даёт слать больше двадцати сообщений в минуту из одного диалога,
  а письма о новых сообщениях приходят не чаще раза в полторы минуты, чтобы почта
  не забивалась.
